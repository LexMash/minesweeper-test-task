Minesweeper Test Task

Gameplay video https://youtu.be/DdlYpOv4LTE

Сделать клон Сапёра (https://minesweeper.online) в Unity, со следующим функционалом:
Внешний вид не важен.
Всё в одной сцене.
Нужно иметь возможность указать размер поля и количество мин (не обязательно делать для этого интерфейс, можно через значения в конфиге).
Не нужно каких-то сложных алгоритмов расстановки мин, достаточно чтобы первый клик всегда был безопасный.
Нужно уметь в любой момент по нажатию клавиши начать заново.
Управление мышкой, левый клик - открываем клетку, правый клик - помечаем "флажком".
При открытии пустой клетки должны по цепочке открываться соседние клетки у которых 0 мин в соседях и их соседи. 
Начинаем в “главном меню” с кнопкой старт. В игровом экране реализовать таймер, который стартует при открытии первой клетки и кнопка паузы, которая открывает окошко с кнопками рестарт, продолжить и выход в главное меню.
Если проиграли или выиграли, показать текст, что игра окончена, показать кнопку начать заново и кнопку выход в главное меню (начать заново нажатием клавиши должно тоже работать).

Проект залить на гитхаб или прислать архивом. Проект должен открываться в Unity. 

Пожелания:
Хочется какую-нибудь стейт машину под состояния игры, чтобы явно видеть лайфтайм игры.
Чтобы в монобехах был только энтри поинт и только то, что нужно для визуала (ui\\сами клетки).
Без детекта кликов рейкастами 
Без неуместных наследований, интерфейсов итд.
Можно с di контейнером.
Без Rx пожалуйста.
